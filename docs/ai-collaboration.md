# AI 협업으로 이 패치를 만든 방식

이 문서는 사람이 어떤 상황에서 무엇을 블로커로 판단했고, 어떤 지시로 작업 흐름을 바꿨는지를 남긴다. 코딩 에이전트에게 레트로 게임 한글패치 같은 장기 역공학 작업을 맡길 때 무엇을 사람이 쥐고 있어야 하는지가 주제다.

기술적으로 무엇을 결정했는지는 [의사결정 흐름](decisions.md)이, 지금 무엇이 열려 있는지는 [현재 상태](status.md)가 담당한다. 이 문서는 그 결정들이 **어떤 개입에서 나왔는지**만 다룬다.

## 기록의 출처와 다듬은 범위

Claude Code와 Codex의 로컬 세션 로그에서 이 저장소를 작업 디렉터리로 삼은 세션만 골라 사람이 직접 입력한 발화를 추출했다. 도구가 자동으로 끼워 넣는 블록(스킬 본문, 컨텍스트 요약, 환경 정보, 플러그인 목록)과 세션 압축으로 중복 기록된 발화는 제외했다.

- 대상 세션: Claude Code 3개, Codex 47개
- 사람이 직접 입력한 발화: **213건**
- 기간: 2026-08-06 20:24 ~ 2026-08-15 17:07 (KST, 9일)
- 같은 기간 커밋: **376개**

인용은 원문을 유지하되, 공개를 전제로 표현이 거친 몇 곳만 뜻을 바꾸지 않는 선에서 다듬었다. 다듬은 인용은 `(표현 완화)`로 표시했다. 시각은 KST이며, 로그 원본의 UTC를 변환한 값이라 커밋 시각과 직접 대조할 수 있다.

## 사람이 쥔 것과 에이전트에 넘긴 것

사람이 끝까지 놓지 않은 것은 넷이다.

1. **번역 범위의 정의** — 무엇을 번역하고 무엇을 원본 그대로 두는가
2. **완료의 기준** — 무엇을 증명해야 "됐다"고 부를 수 있는가
3. **작업 순서** — 지금 무엇부터 깨야 하는가
4. **폐기 판단** — 틀린 경로를 언제 버리는가

반대로 주소 추적, 뱅크 배치, 코드북 설계, 테스트 작성 같은 실행은 거의 전부 에이전트가 맡았다. 사람이 6502 주소를 직접 읽은 흔적은 로그에 없다.
