# 작업 로드맵

이 문서는 전체 한글화의 통과 관문과 순서만 정한다. 현재 수치와 exact ROM은 `status.md`, 블로커는 `open-problems.md`, 실행 경로는 `playtesting.md`를 따른다.

## 완료의 정의

목표는 지원 일본판에서 일본어 표시를 한국어로 바꾸되 원본 영어·숫자·로마자 약어, 게임 진행, 저장 호환과 그래픽을 보존하는 것이다. 최종 ROM은 다음을 모두 만족해야 한다.

- 지원 원본과 번역 입력이 재현 가능하게 결속된다.
- 모든 일본어 저장소와 실제 소비 경로가 설치 계획에 포함된다.
- 모든 동시 표시 수명이 글리프·페이지·매퍼 예산 안에 든다.
- 누적 설치와 최종 설치가 같은 화면·코드북 정책을 쓴다.
- exact-ROM 묶음 실행과 전체 플레이에서 크래시, 일본어 잔존, 진행 불가가 0건이다.
- 배포 패치를 깨끗한 원본에 적용한 결과가 승인한 최종 ROM과 같다.

조사, 정적 설치, 단위 시험, 한 화면 관측과 배포 준비는 서로 다른 관문이다.

## G1. 원본과 렌더 경로

지원 원본 해시, 텍스트 저장소, 인코딩, 글꼴, PPU/CHR 소비자와 화면 상태 생산자를 결속한다.

통과 조건은 일본어 대상 모집단과 각 소비 경로의 소유자가 식별되고, 알려지지 않은 영역을 완료로 세지 않는 것이다.

## G2. 매퍼 변환과 원본 동등성

mapper 165 변환에서 PRG·CHR·SRAM, reset/NMI/IRQ, 원본 CHR 선택과 알려진 mapper writer를 보존한다.

통과 조건은 원본 콘텐츠의 무번역 패리티, 전체 Expected Write, 알려진 양성 writer와 열린 whole-program 경계의 명시다. 열린 간접 edge가 있으면 G2 전체를 완료로 세지 않는다.

## G3. 동적 한글 글꼴

화면 수명마다 필요한 원본 페이지와 한글 글리프를 공급하고, 페이지 게시·무효화·재사용·복귀를 한 계획으로 관리한다.

통과 조건은 대표·최악 수명에서 저장 문자열, 코드북, 실제 CHR-RAM과 네임테이블 소비가 일치하고, 취소·재진입·연속 페이지에서 이전 화면 상태가 새지 않는 것이다.

## G4. 전체 번역 모집단

고정 메뉴, 이름·병종·아이템·지형, 주 대사, 전투 대사, 장 제목, 저장·불러오기, 시설, 사망·패배와 엔딩을 하나의 번역 인벤토리로 결속한다.

통과 조건은 번역 대상 일본어 잔존 0, 구조적 미번역 0, 제어 코드와 포인터 round-trip, 원본 영어·숫자 보존이다.

## G5. 전역 최악 수명과 조판

정적 합집합이 아니라 실제 동시에 보이는 화면·페이지·동적 삽입 단위로 글리프와 폭을 계산한다. 줄이 넘으면 의미와 창 구조를 보고 문장을 재배치하며 무조건 자동 줄바꿈을 쓰지 않는다.

통과 조건은 모든 선언 수명이 페이지·remap·PPU·사이클 예산을 통과하고, 최대 이름·수치·선택지·보더를 포함한 화면이 안정적인 것이다.

## G6. 통합 설치

모든 번역 재료와 typed 런타임 코드를 한 이미지에 Expected Write로 설치한다. 최종 이미지를 다시 읽어 저장소, 포인터, 페이지, 선택기 그래프, 수명 훅과 도메인별 기여를 검증한다.

통과 조건은 선언된 모든 도메인이 하나의 결정적 쓰기 집합에 기여하고, 누적·최종 단계가 서로 다른 정책을 갖지 않는 것이다.

## G7. exact-ROM 회귀

같은 최종 ROM과 파일로 보존한 SaveRAM을 이용해 화면이 아니라 목적별 경로를 묶어 실행한다.

필수 묶음은 다음과 같다.

- 콜드 새 게임, 불러오기와 장 도입
- 메뉴·유닛·소지품·전달·버리기·보관소·시설의 성공·취소·실패·복귀
- 일반 전투·투기장·사운드 테스트, 대사 갱신, 보상과 사망
- 장 완료, 저장 분기, 다음 장 정착, 게임 오버와 엔딩 변형
- 장시간 유휴, 화면 이탈·재진입과 SaveRAM 재로드

통과 조건은 실행 manifest가 exact ROM 해시, 입력 계보, 진입·변형·결과·이탈과 실제 소비를 모두 결속하고 전체 플레이에서 알려진 중대 결함이 0건인 것이다.

## G8. 배포

깨끗한 지원 원본에서 최종 ROM과 패치를 재생성하고 적용 결과를 비교한다. 공개 저장소·배포물에는 원본 미디어, 생성 ROM, 대규모 원문·번역 작업공간, SaveRAM과 내부 QA를 넣지 않는다.

통과 조건은 빌드·정적 보고서·실행 증거·패치 적용 결과·실기 범위가 같은 최종 ROM 해시에 귀속되는 것이다.

## 현재 위치

G1, G4, G5와 G6의 정적 설치는 실질적으로 닫혀 있다. G2는 whole-program 간접 edge 때문에 부분 완료이고, G3와 G7은 최종 exact-ROM 실행 분모가 남아 있다. G8은 시작 전이다.

G2·G3·G6에 걸쳐 파편화돼 있던 전투·대사 런타임 소유권은 통합했고, 누적·통합 ROM과 두 보고서가 리팩터링 전 기준선과 byte-identical임을 확인했다. 현재 기능 동결은 유지한다. 동결을 해제한 뒤 G7의 남은 시설·장 종료 묶음으로 돌아간다. 상세 순서는 `status.md`의 “현재 열린 관문”이 유일한 현재 작업 목록이다.
