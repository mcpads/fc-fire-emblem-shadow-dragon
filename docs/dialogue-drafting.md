# 대사 초벌 작업 지시서

이 문서는 주 대사 한국어 초벌을 직접 작성하는 작업자가 따라야 할 규약이다. 초벌은 번역 완료본이 아니라 문맥과 구조 검증을 거친 검토 후보이며, 실제 대사 원문과 번역문은 이 문서에 복사하지 않는다.

## 기본 원칙

- 작업 수행자가 일본어 원문과 장면 문맥을 읽고 한국어 초벌을 직접 작성한다. 다른 에이전트, 기계 번역, 사전식 일괄 치환에 초벌 작성을 맡기지 않는다.
- 번역 대상은 일본어뿐이다. 일본판에 원래 들어 있는 영어·숫자·로마자 약어는 고치거나 번역하지 않는다.
- 자연스러운 한국어와 인물의 말투를 우선하되 원문의 사실, 관계, 호칭과 감정 강도를 임의로 바꾸지 않는다.
- 초벌을 `complete`로 표시하지 않는다. 사용자가 검토하기 전에는 `needs_human_review`를 유지한다.
- 전체 번역을 먼저 끝내지 않는다. 장면 단위 초벌과 재삽입·글리프 공급·실행 검증을 병행한다.

## 시작 전 고지

초벌을 만들기 전에 사용자에게 다음 내용을 먼저 알린다.

1. 장면과 안정 ID 범위
2. 실제 번역할 줄 수
3. 화자, 청자와 장면 흐름
4. 번역하지 않고 보류할 줄과 그 이유
5. 기존 초벌을 함께 고칠 경우 그 범위

단순히 연속된 줄 수로 묶지 않는다. 입력 대기, 자동 전이와 제어 전환을 확인해 의미가 이어지는 한 장면을 작업 단위로 삼는다.

## 번역 적격 선행 조건

본편 대사를 초벌 대상으로 올리기 전에 전체 줄거리, 장·루트 순서와 주요 관계 변화의 윤곽을 확보한다. 후반의 정체 공개, 관계 변화, 생존·영입·아이템 조건과 결말 분기가 현재 문장의 뜻이나 호칭을 바꿀 수 있는지 먼저 판정한다.

각 작업 단위에는 다음 입력이 있어야 한다.

- 전체 서사에서의 위치와 앞뒤 사건
- 실제 소비 순서와 발동 조건
- 화자·청자와 현재 관계
- 적용할 고유명사·용어·문체 결정과 그 승인 상태
- 생존·영입·선택·소지품에 따라 갈리는 변형
- 의미를 바꿀 수 있는 미확정 질문

이 가운데 하나라도 번역 결과를 바꿀 수 있는데 미확정이면 해당 줄은 번역 적격이 아니다. 전체 줄거리 윤곽이 있다는 이유만으로 모든 대사를 한꺼번에 적격으로 올리지 않는다.

## 문맥 확인

번역하기 전에 가능한 범위에서 다음을 확인한다.

- 실제 화면에 표시되는 순서와 페이지 경계
- 화자와 청자, 인물 관계와 호칭
- 장·지도·전투·상점·엔딩 등 대사가 놓인 상황
- 버튼 입력에 대한 반응인지 무입력 자동 전이인지
- 앞뒤 레코드 전환 뒤에도 이어지는 문장인지
- 점멸이나 애니메이션 때문에 한 프레임에서 빠질 수 있는 요소가 있는지

화면 표시와 추출 결과가 다르거나 화자를 확정할 수 없으면 문장을 꾸며내지 않는다. 확인된 줄만 번역하고 의심되는 줄은 `untranslated`로 보류한다.

## 초벌 작성

1. 안정 ID와 원문 결속 필드를 먼저 확인한다.
2. 장면 전체를 읽고 이름·지명·호칭의 표기를 정한다. 확정되지 않은 고유명사는 초벌 용어 후보로 일관되게 쓰고 보고할 때 밝힌다.
3. 직역보다 실제 대화로 자연스러운 한국어를 쓴다. 다만 정보의 추가·삭제, 인물 관계 변경, 과도한 현대화는 하지 않는다.
4. 원문의 줄바꿈과 화면 폭을 고려하되 의미를 줄여 공간 문제를 숨기지 않는다.
5. 작업공간에서는 `korean`과 `status`만 고친다. 안정 ID, 원문, 저장 해시, 주소, 길이와 구조 필드는 수정하지 않는다.
6. `{SP}`, `{ED}`, `{EE}`, `{EF}`, `{E4:..}`, `{E6:..}` 같은 보호 토큰은 원문과 같은 종류·순서·개수로 유지한다.
7. 작업공간이 실제 공백 대신 `{SP}`를 요구하면 한국어 필드에도 문자 공백을 넣지 않는다.
8. 번역한 줄은 모두 `needs_human_review`로 표시한다.
9. 이름·아이템·병종·수량처럼 받침 여부가 실행 때 달라지는 동적 토큰 뒤에는 `는`, `가`, `를`, `로`, `이나` 같은 한쪽 조사만 고정하지 않는다. 런타임 조사 선택기가 없는 현재 구조에서는 `은(는)`, `이(가)`, `을(를)`, `과(와)`, `(으)로`, `(이)나`처럼 모든 입력에 성립하는 중립 표기를 쓴다. 숫자처럼 발음 조건이 소스에서 고정된 선택자는 그 의미를 정확히 결속한 경우에만 단일 조사를 허용한다.

추출된 일본어처럼 보이더라도 실행 화면에 나타나지 않거나 전후 레코드 상태와 합쳐져 다른 문자를 만드는 바이트는 번역하지 않는다. 먼저 소비자와 경계를 고친 뒤 다시 초벌 대상으로 올린다.

## 검증

한 장면의 초벌을 작성한 뒤 다음을 실패 폐쇄형으로 확인한다.

1. 지원 원본과 안정 ID·원문 해시 결속
2. 보호 토큰의 종류·순서·개수
3. 기존 영어·숫자·로마자 보존
4. 한국어 필드의 일본어 잔존과 허용되지 않은 문자
5. 논리 줄 폭과 저장 공간 배치
6. 검토 대기 번역에서 계산한 실제 한글 글리프 집합
7. 재추출 뒤에도 기존 초벌이 같은 안정 ID에 보존되는지

길이 또는 글리프 예산을 넘으면 자동 축약하거나 뜻을 버리지 않는다. 문제가 난 줄, 초과량과 가능한 자연스러운 대안을 분리해 검토한다. 구조 검증이 통과해도 실제 화면의 줄바꿈, 초상화, 창, 원본 영어, 전환과 이탈 복구는 실행으로 다시 확인한다.

## 작업 결과 보고

한 단위를 마칠 때는 다음만 요약한다.

- 새로 초벌을 만든 줄 수와 누적 검토 대기 줄 수
- 장면 범위와 적용한 주요 용어 후보
- 보류한 줄과 구조상 이유
- 검증 명령의 통과·실패 및 실패한 정확한 조건
- 다음 초벌 또는 구현 관문

사용자가 문장을 검토해 승인하거나 수정하기 전에는 초벌을 완료 번역으로 세지 않는다.
