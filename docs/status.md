## 검증 결과

- 입력: 지원 일본판 SHA-1 `0179c550d424e0397496078789e7b116601d120c`
- PoC ROM SHA-1: `4529ea8d3724646dc8f4b19e68895b19ad95e2a8`
- 변경 바이트: 119개, 모두 등록된 설정 표·일본어 CHR 타일 쓰기 범위 안
- 영문 패치 ROM 입력: 일본판 원본 SHA-1 불일치로 거부, 산출물 없음
- 빌드 검사: `cargo test --all-targets` 10개 통과, `cargo clippy --all-targets -- -D warnings` 통과
- 런타임 경로: 타이틀 → 처음부터 → 슬롯 1 → 1장 대화 진행 → SELECT 맵 메뉴 → 설정

현재 빌드는 전역 가나 타일 12개를 임시 재사용하므로 설정 화면 밖의 일본어가 깨진다. 이는 한글 표시 소비 경로만 검증하는 PoC 한계이며, 정식 패치에는 허용되지 않는다. 일본판에 원래 존재하는 영어를 번역하거나 손상하는 것도 허용되지 않는다.
